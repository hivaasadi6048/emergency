# فیکس فاز ۵ — نسخه ۲ (C-017 / C-018)

## این بسته چیه؟

رفع دو باگ مهم صف موقعیت که در بررسی فاز ۵ پیدا شد:

1. **C-017 — uuid از لحظه ثبت:** هر نقطه موقعیت، همان لحظه‌ی ثبت در سمت Kotlin یک `client_uuid` می‌گیرد که داخل صف پایدار ذخیره می‌شود. قبلاً uuid در Dart موقع آپلود ساخته می‌شد → بعد از ری‌استارت اپ، همان نقاط با uuid تازه دوباره آپلود و **ردیف تکراری در دیتابیس** ساخته می‌شد.
   - این روش، رویکرد هش Dart در commit `0adb880` را هم جایگزین می‌کند — چون آن روش پنجره‌ی ۲۰ نقطه‌ای و انتساب نقاط session قبلی به session جدید را حل نمی‌کرد.
2. **C-018 — تخلیه صف بعد از تأیید سرور (ack/drain):** صف نقاط قبلاً **هرگز** تخلیه نمی‌شد و Dart فقط ۲۰ نقطه آخر را می‌دید → قطعی شبکه بیشتر از ~۳ دقیقه یعنی گم‌شدن نقاط. حالا:
   - `getPendingPoints` → کل صفِ تأییدنشده (نه فقط ۲۰ تای آخر)
   - `ackUploadedPoints` → نقطه فقط بعد از پاسخ موفق سرور از صف خارج می‌شود
   - ذخیره صف اتمیک شد (خراب‌نشدنی در مرگ پروسه)
   - نقاط مربوط به session های قبلی بدون آپلود تخلیه می‌شوند (به session جدید نسبت داده نمی‌شوند)

**مبنای این بسته:** commit `82faa06` — یعنی دقیقاً همان HEAD فعلی گیت‌هاب بعد از پوش شما. هیچ فایل دیگری دست نخورده.

## نصب (قدم به قدم)

### قدم ۰ — بکاپ
از پوشه `G:\Emergency` یک کپی بگیر (یا در VSCode: راست‌کلیک روی پوشه در Explorer → Copy → Paste و نامش بگذار `Emergency-backup`).

### قدم ۱ — کپی فایل‌ها
محتویات پوشه‌ی داخل zip را روی `G:\Emergency` کپی کن و **Replace** کن.
(ساختار پوشه‌ها عیناً مثل ریپو است؛ ۶ فایل را جایگزین می‌کند.)

### قدم ۲ — در ترمینال VSCode (در `G:\Emergency`):
```
flutter pub get
flutter analyze
```
⚠️ خروجی `flutter analyze` **باید دقیقاً «No issues found!»** باشد. اگر نبود، خروجی را برایم بفرست.

### قدم ۳ — اجرا:
```
flutter run
```

## تست‌های تأیید (۴ سناریو روی A21s)

| # | سناریو | نتیجه درست |
|---|---|---|
| ۱ | جریان عادی: ورود → SOS → چند دقیقه صبر | نقاط در سرور ثبت می‌شوند؛ در اپ وضعیت ACTIVE/DEGRADED |
| ۲ | ری‌استارت اپ وسط سشن: SOS فعال → اپ را force-stop کن → دوباره باز کن | دیتابیس **بدون ردیف تکراری** برای همان نقاط؛ آپلود ادامه پیدا می‌کند |
| ۳ | قطعی شبکه: اینترنت گوشی را ۵ دقیقه خاموش کن → بعد روشن کن | نقاطِ دورانِ قطعی **گم نمی‌شوند** — همه با هم بچ می‌شوند و بعد از وصل آپلود می‌شوند |
| ۴ | صفحه خاموش ۱۰ دقیقه | نوتیفیکیشن تازه می‌ماند یا وضعیت DEGRADED صادقانه |

## دیدن لاگ‌ها (کامپیوتر + USB + دیباگ):
```
adb logcat | findstr /C:"EmergencyLocSvc" /C:"PointQueue" /C:"locations."
```
لاگ‌های کلیدی: `locations.uploaded ... drained=N` یعنی آپلود و تخلیه موفق؛ `locations.staleDiscarded` یعنی نقاط سشن قبلی دور ریخته شدند.
